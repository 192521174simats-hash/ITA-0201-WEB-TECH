About XHTML

XHTML stands for Extensible HyperText Markup Language.

XHTML is a stricter version of HTML.


Features of XHTML

  • All tags must be written in lowercase.
  • Every tag must have a closing tag.
  • Attribute values must be enclosed in quotation marks.
  • Empty elements must be self-closing.
