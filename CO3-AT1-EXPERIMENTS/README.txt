CO3 - Assessment 1 - Experiments
=================================

Experiment 1 - DOM-Based Interactive Student Registration Preview
-------------------------------------------------------------------
Folder: Experiment1_DOM/
File:   index.html

How to run:
1. Just double-click index.html to open it in any browser
   (Chrome/Firefox/Edge). No server needed.
2. Fill in Name, Register Number, Department, Year of Study.
3. Click "Display Profile" to see the generated profile card
   (built using createElement/textContent, shown via classList).
4. Click "Remove Profile" to remove it from the DOM.

Concepts used: getElementById(), querySelector(), createElement(),
textContent, addEventListener(), classList.


Experiment 2 - Servlet-Based Student Result Processing
---------------------------------------------------------
Folder: Experiment2_Servlet/
  src/ResultServlet.java          -> the servlet source code
  WebContent/index.html           -> HTML form (POST method)
  WebContent/WEB-INF/web.xml      -> deployment descriptor

How to deploy on Apache Tomcat (Eclipse or manual):

OPTION A - Using Eclipse (recommended for labs):
1. Open Eclipse -> File -> New -> Dynamic Web Project.
   Name it e.g. "StudentResultApp", target runtime = Apache Tomcat.
2. Copy ResultServlet.java into: src/ (default package).
3. Replace/merge the generated WebContent/index.html and
   WebContent/WEB-INF/web.xml with the provided files.
4. Right-click project -> Run As -> Run on Server (choose Tomcat).
5. In the browser, go to:
   http://localhost:8080/StudentResultApp/index.html
6. Fill the form and submit - the servlet (/ResultServlet) will
   process it and display Total, Average, Highest Mark and Pass/Fail.

OPTION B - Manual deployment (without Eclipse):
1. Locate your Tomcat installation, e.g. C:\apache-tomcat-9.x\
2. Create folder: webapps/StudentResultApp/
3. Copy WebContent/index.html into that folder.
4. Copy WebContent/WEB-INF/ (with web.xml) into that folder too,
   i.e. webapps/StudentResultApp/WEB-INF/web.xml
5. Compile the servlet against the Tomcat servlet-api jar:
   javac -cp "C:\apache-tomcat-9.x\lib\servlet-api.jar" -d ^
       webapps\StudentResultApp\WEB-INF\classes src\ResultServlet.java
   (On Linux/Mac use : instead of ; and forward slashes.)
6. Start Tomcat (bin/startup.bat or bin/startup.sh).
7. Open: http://localhost:8080/StudentResultApp/index.html
8. Submit the form to see the result page generated by the servlet.

Validation implemented in the servlet:
- Missing Name / Register Number / any mark -> error message shown.
- Non-numeric marks -> error message shown.
- Marks outside 0-100 -> error message shown.
- Pass/Fail rule used: PASS only if all 3 subject marks are >= 40.

Note: All student data (name, marks, etc.) is read into LOCAL
variables inside doPost() for each request, so the servlet is safe
when multiple students submit the form at the same time (no shared
mutable instance/static fields are used for request data).
